The funniest sick-day excuse: "I can't come in today — my bed has filed a
formal complaint about my absence, and HR (my cat) has approved emergency
cuddles only." The program writes it to `/output/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22, standard library only, no network. Two runs produce byte-identical output.
