My entry is the excuse: "My goldfish filed a formal complaint about my management style, so I'm staying home to mediate." Running the program writes that one line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set), with no trailing newline.

## Run it

```sh
node main.ts
```

Runs on Node 22 using only the standard library, with no network access; two runs produce byte-identical output.
